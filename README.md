- 会员运营：会员等级、积分体系、成长任务，提升用户复购率

- 内容运营：文章管理、广告管理、Banner设置，打造农场内容生态

4. 后台管理系统

- 系统概况：运营数据总览，农场状态、订单量、会员数一目了然

- 权限管理：多角色分配，管理员、商家、操作员权限区分，安全可控

- 日志管理：后台操作日志、登录日志，全程可追溯

- 接口管理：快递、物流、短信接口全打通，运营更高效

🔧 部署教程（新手必看）

前提准备

1. 准备一台服务器（推荐阿里云、腾讯云，配置1核2G及以上）

2. 安装PHP、MySQL、Nginx环境（可使用宝塔面板快速部署）

3. 已注册微信小程序账号（如需小程序端，可选）

狗凯之家源码网bygoukai.com

步骤2：配置数据库

1. 登录MySQL，创建新数据库（编码：utf8mb4）

2. 导入源码根目录下的 sql/ba_jie_nong_chang.sql 文件

3. 修改源码根目录config/database.php 文件，填写数据库信息（主机、账号、密码、数据库名）

步骤3：配置网站

1. 宝塔面板添加站点，绑定域名（无域名可使用服务器IP）

2. 设置网站根目录为源码所在目录，开启PHP版本（7.3-7.4）

3. 设置伪静态（ThinkPHP5伪静态规则）：

location / {
    if (!-e $request_filename) {
        rewrite  ^(.*)$  /index.php?s=$1  last;
        break;
    }
}

步骤4：初始化系统

1. 访问域名（或IP），进入系统安装页面，按照提示完成安装

2. 默认后台地址：http://你的域名/admin

3. 默认账号：admin，默认密码：123456（登录后请及时修改密码）

步骤5：小程序配置（可选）

1. 打开微信开发者工具，导入源码根目录下的 miniprogram 文件夹

2. 修改小程序配置文件 app.js 中的域名，替换为自己的网站域名

3. 在微信公众平台提交小程序审核，审核通过后即可上线使用

⚠️ 常见问题

1. 安装时提示数据库连接失败

检查 config/database.php 文件中的数据库信息是否正确，确保MySQL服务正常运行，数据库账号有读写权限。

2. 后台登录后空白/报错

1. 检查PHP版本是否符合要求（7.3-7.4）；2. 给源码目录设置775权限（宝塔面板可直接设置）；3. 清除浏览器缓存后重新登录。

3. 小程序无法访问接口

在微信公众平台「开发管理」→「服务器域名」中，添加自己的网站域名（request合法域名、uploadFile合法域名）。

4. 上传文件提示权限不足

给 public/upload 文件夹设置777权限，确保文件可正常上传。
